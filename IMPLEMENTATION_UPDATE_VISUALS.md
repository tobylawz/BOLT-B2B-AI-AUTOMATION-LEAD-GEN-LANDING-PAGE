# Implementation Plan: Make Meridian Systems Landing Page Modern and Dynamic

## Summary
The goal is to make the page feel alive — things move, respond to the cursor, animate as you scroll, and give a sense of depth and craftsmanship. Every section gets at least one dynamic element, but nothing should feel flashy or distracting. The overall vibe stays premium and understated, just with a pulse.

## Progress Checklist

### 1. Living, Animated Background
- [ ] Add a mouse-following spotlight glow in the hero section that tracks the visitor's cursor, making the page feel interactive immediately
- [ ] Add slow-moving aurora-style gradient blobs (emerald and subtle blue) that drift behind content, giving depth without distracting
- [ ] Upgrade the static grid to fade out from the center using a radial mask, so it feels intentional rather than flat
- [ ] Add a thin scroll progress bar at the very top of the page that fills as you scroll

### 2. Dynamic Hero Section
- [ ] Add a floating, animated "automation workflow" visual below the hero text — small connected cards or nodes that pulse and animate, showing data flowing between steps
- [ ] Add a subtle typewriter or gradient-shift effect on the hero headline to draw the eye
- [ ] Make the hero badge ("AI Automation Agency") glow softly with a pulsing emerald ring instead of a static dot

### 3. Interactive Cards and Micro-interactions
- [ ] Add a 3D tilt effect on the "For / Not For" cards and the process step cards so they respond to mouse movement with a subtle parallax
- [ ] Add glow-on-hover to all cards — a soft emerald or white border glow that follows the cursor position
- [ ] Make the CTA buttons magnetic — they shift slightly toward the cursor when nearby, and emit a glow on hover
- [ ] Add animated underline reveals on nav and footer links

### 4. Animated Credibility Section
- [ ] Make the stat numbers (8+, 120+, 14, 0) count up from zero when they scroll into view, with a smooth easing animation
- [ ] Add a subtle shimmer/sweep effect across the stats grid when it enters view
- [ ] Make the industry tags gently float in with a staggered cascade instead of appearing all at once
- [ ] Replace the abstract placeholder credibility icons with animated mini-diagnostics (small bar charts or pulse lines that animate)

### 5. Enhanced Scroll Animations
- [ ] Upgrade the existing fade-up animation to include a blur-to-sharp transition for a more cinematic feel
- [ ] Add staggered reveals within each section so items cascade in sequence rather than appearing together
- [ ] Add parallax depth to section backgrounds — background elements move slower than foreground content as you scroll

### 6. Visual Polish and Depth
- [ ] Add subtle gradient accents (emerald-to-transparent) behind section headings to create visual hierarchy
- [ ] Add glassmorphism to the nav bar and key cards — translucent backgrounds with backdrop blur and subtle border gradients
- [ ] Add a noise/grain texture overlay at very low opacity to give the dark background a premium, tactile feel
- [ ] Add soft section-specific gradient glows that match each section's purpose (emerald for "for you", neutral for "not for you")
